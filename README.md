# 📚 Projeto Semestral – PAA

## Sobre o projeto
Este repositório contém os arquivos desenvolvidos para o projeto semestral da disciplina de **Projeto e Análise de Algoritmos (PAA)**.
O projeto tem como objetivo trabalhar com algoritmos de ordenação, explorando suas implementações, funcionamento e análise de desempenho.

## 📁 Arquivos do repositório
O repositório está organizado em três arquivos compactados:

| Arquivo | Descrição |
|---|---|
| `BubbleInsertion_paa.zip` | Arquivos relacionados à implementação dos algoritmos Bubble Sort e Insertion Sort. |
| `Programa.zip` | Arquivos do programa principal de execução do projeto. |
| `QuickMergeSelection_paa.zip` | Arquivos relacionados aos algoritmos Quick Sort, Merge Sort e Selection Sort. |

## 🔢 Algoritmos de ordenação
O projeto aborda cinco algoritmos clássicos:

- **Bubble Sort**
- **Insertion Sort**
- **Selection Sort**
- **Merge Sort**
- **Quick Sort**

## 🎯 Objetivos
- Implementar algoritmos de ordenação.
- Compreender o funcionamento de cada algoritmo.
- Analisar a complexidade computacional.
- Comparar o desempenho dos diferentes métodos.
- Aplicar os conceitos estudados na disciplina de Projeto e Análise de Algoritmos.
